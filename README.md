# 佐々木 正吾 — Researcher website

GitHub Pagesでそのまま公開できる、ビルド不要の個人サイトです。HTML・CSS・JavaScriptのみを使用し、外部ライブラリ、外部フォント、解析サービスに依存しません。

## サイト構成

```text
researcher-site/            ← この中身を公開リポジトリのルートに置く
├── index.html              # 日本語プロフィール
├── en/index.html           # 英語プロフィール
├── start/
│   └── index.html          # 日常用リンク集
├── assets/
│   ├── css/style.css       # 共通デザイン・画面幅・ダークモード
│   ├── js/
│   │   ├── theme.js        # 表示モード切替・保存
│   │   ├── links.js        # リンク集の編集場所
│   │   └── start.js        # 絞り込み・キーボード操作
│   └── images/
│       ├── favicon.svg
│       └── blackboard-v2.jpg  # プロフィール上部の黒板画像
├── .nojekyll               # Jekyll処理を無効化
├── .gitignore
└── README.md
```

公開プロフィールは、目次と本文を並べた簡素な1ページ構成です。プロフィール／研究関心／論文・学会発表／授業・教材／研究・開発／連絡先に直接移動できます。スマートフォンでは目次が本文の上に移動します。件数が増えた段階で各セクションを専用ディレクトリへ分割できます。空のページを最初から量産しない構成にしています。

すべての内部URLは相対パスです。ユーザーサイト、リポジトリ名付きのプロジェクトサイト、独自ドメインで利用できます。プロジェクトサイトのスタートページは `/リポジトリ名/start/` になります。

## ローカルで確認する

Python 3がある場合、`researcher-site` フォルダで次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

- 日本語プロフィール: <http://127.0.0.1:8000/>
- 英語プロフィール: <http://127.0.0.1:8000/en/>
- スタートページ: <http://127.0.0.1:8000/start/>
- 終了: ターミナルで `Ctrl+C`

`index.html` を直接ブラウザで開くこともできますが、URLの移動やテーマ保存の確認はHTTPサーバーで行ってください。npmのインストール・ビルド処理は不要です。

## GitHub Pagesで公開する

1. 自分のGitHubアカウントでリポジトリを用意します。アカウント直下のサイトなら `<ユーザー名>.github.io`、プロジェクトサイトなら任意のリポジトリ名にします。
2. この `researcher-site` フォルダの**中身**をリポジトリのルートへ追加します。フォルダ自体を1段ネストして置かないでください。`.nojekyll` も含めてください。既存のリポジトリなら既存ファイルとの差分を確認してください。
3. 内容をコミットし、`main` ブランチへpushします。
4. GitHubのリポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch** に設定します。
5. Branchを **main**、フォルダを **/(root)** にして保存します。
6. デプロイ完了後、Pages設定画面に表示されるURLを確認します。公開ページと `start/` の両方を開いてください。

以降は編集内容を同じブランチへpushすると反映されます。公開先アカウント・リポジトリは未指定のため、この成果物にはリモート設定や公開済みURLを含めていません。

公式手順: [GitHub Pagesの公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## スタートページのリンクを編集する

`assets/js/links.js` の配列だけを編集します。HTMLの修正は不要です。各カテゴリの `links` にオブジェクトを追加すると表示されます。

```js
{
  name: 'リンクの名前',
  url: '', // 確認済みの https:// URL を入力
  description: '短い説明',
  keywords: ['日本語の別名', '検索キーワード'],
},
```

- `name`：表示名（必須）
- `url`：移動先。空文字 `''` は「未設定」と表示され、開く対象になりません。HTTP / HTTPSのみ許可します。
- `description`：補足説明（省略可）
- `keywords`：別名・検索語の配列（省略可）
- 削除：該当オブジェクト全体を削除します。
- 並べ替え：配列内の順序を変更します。
- カテゴリ追加：`{ id: '独自の識別子', name: 'カテゴリ名', links: [] }` を追加します。
- サイト内の相対URLを登録する場合、`start/` からの相対パスで指定します。例：`../#projects`。

大学ポータル、LMS、Webmail、図書館は未設定です。所属・アカウントによって入口が異なるため、実際に使っている正式なURLを登録してください。Zoteroは公開トップページを入口にしています。必要ならログイン後の適切なライブラリURLに変更してください。

### キーボード操作

| 操作 | 動作 |
| --- | --- |
| 入力 | 名前・説明・キーワード・カテゴリを絞り込み |
| スペース区切り | すべての検索語を含むリンクを表示 |
| ↑ / ↓（検索欄内） | 表示中のリンクを前後に選択。端で循環 |
| Enter（検索欄内） | 選択中のリンクを同じタブで開く |
| Esc（検索欄内） | 絞り込みを解除 |
| /（入力欄の外） | 検索欄へフォーカス |
| Tab / Shift+Tab | 標準のフォーカス移動 |
| Enter（リンク上） | フォーカス中のリンクを開く |
| GoogleでWeb検索 | 入力文字列をGoogle検索へ送る |

検索結果の先頭が初期選択です。選択中のリンクには背景色と左線を付け、読み上げ用の通知も更新します。検索結果が0件の場合、Enterでは移動しません。Web検索は専用ボタンを明示的に押した場合にだけ実行します。日本語IMEの変換確定ではリンクを開かないようにしています。

マウス・トラックパッドを使用するPCでは読み込み直後に検索欄にフォーカスします。タッチ端末では画面をキーボードで塞がないよう、自動フォーカスを抑制します。検索欄のタップ、または外付けキーボードの `/` で入力できます。

公開したスタートページのURLをChromeの起動時ページやホームボタンの移動先に指定すると使えます。標準の「新しいタブ」ページを置き換える機能はこのサイトには含めていません。

### 公開範囲

`/start/` も公開される静的ページです。`noindex` は検索結果への掲載を抑える指定で、アクセス制限ではありません。リンクデータにパスワード、アクセストークン、秘密情報を含めないでください。テーマ設定だけをブラウザ内に保存し、検索語は保存しません。登録リンクの絞り込み中に外部へ通信しません。

## デザイン・アクセシビリティ

- 初期状態はOSのライト／ダーク設定に追従。「表示」ボタンで自動 → ライト → ダークと切り替え、選択を同じブラウザ内に保存します。
- 保存機能が利用できない場合も切り替えは動作します。
- PC、タブレット、スマートフォンに合わせて段組みを変更します。
- セマンティックな見出し・ランドマーク、本文へのスキップリンク、フォーカス表示、読み上げ通知を用意しています。
- 公開プロフィールはJavaScriptが無効でも読めます。リンク集にはJavaScriptが必要ですが、無効時には案内と主要リンクを表示します。
- 色・余白・文字サイズは `assets/css/style.css` 冒頭の変数と各クラスを編集します。

## 独自ドメインを設定する

1. 使用するドメインを取得し、GitHub側で所有権を検証します。
2. リポジトリの **Settings → Pages → Custom domain** にドメインを入力します。
3. ドメイン管理会社で、GitHubの公式手順に従ってDNSを設定します。サブドメインにはCNAME、apexドメインにはA / AAAAまたは対応するALIAS / ANAME設定を使用します。IPアドレスなどの値はその時点の公式資料で確認してください。
4. ブランチ公開では、GitHubが公開元にドメイン名を記した `CNAME` ファイルを作成します。手元にも取り込み、以後の更新で消さないでください。
5. DNS反映・証明書発行後に **Enforce HTTPS** を有効にして動作を確認します。

ドメイン未指定のため、現時点では `CNAME` は作成していません。相対パスのため基本的なサイト内リンクはそのまま使えます。将来canonical URLやOGP画像を追加する場合は、公開先確定後の絶対URLを指定してください。

公式資料: [独自ドメインの設定](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site) / [独自ドメインの管理](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)

## プロフィール画像

日本語・英語のプロフィール見出しの上に、テンソル積の右完全性の証明を筆記体の英語と数式で記した、きれいな深緑の黒板を斜めから写した写真風のAI生成画像を配置しています。本人の研究室や実際の授業を撮影した写真ではありません。表示用のJPEGは `assets/images/blackboard-v2.jpg`、配置は各言語HTMLの `.profile-image`、サイズ指定は共通CSSです。画像を差し替える場合は `src`・`alt`・`width`・`height` も更新してください。

黒板画像の上のタイトルは、各言語HTMLの `.profile-banner-title` で編集できます。暗さは共通CSSの `.profile-banner::after` の黒の不透明度（現在34%）で調整します。文字は画像に焼き込まずHTMLで表示しています。

タイトルは黒板の左下に、氏名と小さな補足表記を配置しています。氏名は `.banner-name`、補足は `.banner-subtitle` で編集できます。日本語は明朝系のシステムフォントを使用し、英語ではセリフ体になります。
